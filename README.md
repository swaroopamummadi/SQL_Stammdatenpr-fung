# SQL_Stammdatenpr-fung
SQL-Projekt: Stammdatenprüfung und Datenqualität
Projektbeschreibung

In diesem Projekt habe ich SQL verwendet, um Stammdaten zu analysieren und die Datenqualität zu prüfen.

Das Projekt zeigt, wie SQL-Abfragen genutzt werden können, um fehlende Werte, mögliche Duplikate und fehlerhafte Stammdaten zu erkennen.

Ziel des Projekts

Das Ziel ist es, Daten systematisch zu prüfen, Fehler zu erkennen und die Daten für weitere Analysen mit Excel oder Power BI vorzubereiten.
##Durchgeführte Aufgaben##
- Stammdaten mit SQL analysiert,
- Fehlende Werte mit IS NULL geprüft,
-Mögliche Duplikate identifiziert,
-Daten mit WHERE gefiltert,
-Daten mit ORDER BY sortiert,
-Daten mit GROUP BY gruppiert,
Fehler mit CASE WHEN kategorisiert
Datensätze mit UPDATE korrigiert
SQL-Abfragen für Datenqualitätsprüfungen erstellt
##Verwendete SQL-Kenntnisse##
1.SELECT
2.WHERE
3.IS NULL
4.CASE WHEN
5.GROUP BY
6.ORDER BY
7.COUNT
8.UPDATE
